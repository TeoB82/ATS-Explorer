How to use the ATS Eplorer and its three panels.

On the left: control panels
On the right: operation points 
- Flux space: coordinates \phi_+ and \phi_- 
- Bias space: coordinates B_1=E_+/E_J cos(\phi_+)cos(\phi_-)-E_-/E_J sin(\phi_+)sin(\phi_-) and B_2=E_+/E_J sin(\phi_+)cos(\phi_-)+E_-/E_J cos(\phi_+)sin(\phi_-)

Set the fabrication parameters: bias parameter \zeta = n^3 E_+/E_J, asymmetry parameter d = E_-/E_J, number of central JJ n

1. PANEL "Independent \phi_\pm":
   Move phi_\pm along vertical and horizontal lines in the flux space, this is reflected in moving along a circle and an ellipse
2. PANEL "g_3=0" line:
   Move phi_\pm locked together by g_3=0 (B_2=0) along the blue line on the left (selected by an index k), this is reflected in moving along B_1
3. PANEL "g_4=0" line:
   Move phi_\pm locked together by g_4=0 along red curves, selected according to their central points, this is reflected in moving along an arch in the bias space
